# 🍕 Zomato Restaurant Finder

A modern, responsive restaurant discovery application built with **vanilla JavaScript, HTML5, and CSS3**. This project showcases a Zomato-like user interface where users can browse restaurants and apply multiple filters to find their perfect dining choice.

---

## ✨ Features

- 🔍 **Advanced Filtering System**
  - Sort by Rating
  - Price Range (High to Low / Low to High)
  - Distance from your location
- 🏷️ **Restaurant Filters**
  - View restaurants with special offers
  - Filter by minimum rating (4.5+)
  - Find restaurants serving alcohol
  - Check which restaurants are open now

- 🎨 **Responsive Design** - Works seamlessly on desktop and mobile devices

- 📊 **Dynamic Restaurant Cards** - Display restaurant details including ratings, pricing, location, and cuisine type

- ⚡ **Smooth User Experience** - Interactive popups and instant filter application

---

## 🛠️ Technologies Used

- **HTML5** - Semantic markup and structure
- **CSS3** - Modern styling and responsive layout
- **Vanilla JavaScript (ES6)** - Pure JavaScript, no frameworks
- **JSON** - Restaurant data storage

## 🚀 How to Use

### Installation & Setup

1. **Clone or download** this repository to your local machine

2. **Navigate** to the `Project_zom` folder

3. **Open** `index.html` in your preferred web browser

That's it! 🎉 No installation steps needed - it's a pure client-side application.

## 🎯 Features Explained

### Filter by Sorting

Click the **"SORT"** button to open the filter popup with options to:

- Sort restaurants by their rating
- Sort by price (High to Low or Low to High)
- Sort by distance from your location

### Quick Filters

Use the quick filter buttons in the header to instantly see:

- **Offers** - Restaurants with active discounts
- **Rating 4.5+** - Only highly-rated restaurants
- **Serves Alcohol** - Restaurants with liquor options
- **Open Now** - Currently operational restaurants

### Restaurant Cards

Each restaurant card displays:

- Restaurant name and cuisine type
- Star rating
- Price range for two people
- Location and distance
- Active offers
- Operating status
